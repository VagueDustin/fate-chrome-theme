# Security

## Reporting a vulnerability

Please report it privately through GitHub rather than in a public issue: on this repository's
**Security** tab, choose **Report a vulnerability** (private vulnerability reporting). The report is
visible only to the maintainer until a fix is published.

Include what you found, how to reproduce it, and the version you saw it in.

## Supported versions

Only the latest release, as published on the Chrome Web Store and on the Releases page, receives
fixes.

## Scope

The theme is a manifest and images. It requests no permissions, runs no code in the browser and makes
no network requests. The build scripts in this repository run only on the machine that builds the
theme.
